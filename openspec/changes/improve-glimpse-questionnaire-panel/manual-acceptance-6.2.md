# 任务 6.2 — 真实 Glimpse 窗口人工验收

这一步无法由 Agent 独立完成：需要在装有 `glimpseui` 的 Pi 会话中真实打开面板，确认 `window.glimpse.send`
的载荷被原生端接收。其余 23 项任务已有自动化或浏览器验证覆盖，**只有这一层是自主验证盲区**。

## 前置检查

- [ ] `~/.pi/agent/npm/node_modules/glimpseui/src/glimpse.mjs` 存在（否则面板会降级到 TUI，测不到目标路径）
- [ ] 当前 Agent 空闲（`/xpi-research` 在忙碌时会拒绝启动）
- [ ] 扩展已加载。日常开发用软链 + 热载：
      `ln -s "$PWD" ~/.pi/agent/extensions/xpi-research` 然后在会话内 `/reload`；
      一次性冒烟用 `pi -e ./src/index.ts`

## A. 提交路径（正向）

- [ ] `/xpi-research <任意目标>` 启动，面板以**分步**布局打开，一次一题
- [ ] 顶部显示 `问题 1 / N`、可点击圆点、`已答 0 / N`
- [ ] 往返切换步骤、选一个普通选项

  **预期**：圆点变为已作答态、计数与进度轨同步、再次回到该题时选中项**已还原**

- [ ] 在多选题上勾选 1–2 个选项，再勾「自定义…」并输入一句自填文本

  **预期**：自定义输入框展开并自动聚焦；该项与普通选项**并存**（多选）

- [ ] 在最后一个问题点主操作（此时按钮应显示「下一步」而不是「提交」）

  **预期**：面板落到汇总页（`确认 / N`）而不是直接回传载荷

- [ ] 也可用步骤条末位的 ✓ 圆点直接进入汇总页

  **预期**：列出所有步骤（含说明类问题）、未作答的显示为斜体「未作答」、点击条目可跳回该题

- [ ] 检查信息类问题那一行的「答案」位置

  **预期**：显示「无需作答」，而不是 `说明` / `info` 这样的类型名

- [ ] 在汇总页的反馈框写一句话，点「提交」

  **预期**：Agent 收到 `cancelled: false`，且

  - 单选答案是选项 label **或**你自填的文本
  - 多选答案 = 选项（按问卷声明顺序）+ 末尾**一项**自填文本
  - 汇总反馈出现在独立的 `feedback` 字段，**不在** `answers` 里

- [ ] 记录实际回传内容：

  ```text
  answers:  ...
  feedback: ...
  ```

## B. 取消路径

- [ ] 重新打开面板，按 `Esc`

  **预期**：Agent 收到 `cancelled: true` 且 `answers` 为空对象

- [ ] 再打开一次，直接**关闭窗口**（不点任何按钮）

  **预期**：同样按取消处理（`prompt()` 返回 `null`），不是"用户选了空答案"

- [ ] 再打开一次，点「取消」按钮

  **预期**：与 `Esc` 一致

## C. 必答拦截

- [ ] 在必答题未作答时点「下一步」

  **预期**：**停在原题**并显示内联错误，不静默跳过

- [ ] 在**信息类**问题上点「下一步」（即使该题在问卷里被标成必答）

  **预期**：正常前进到下一题；不出现「必答」错误，主按钮不失效

- [ ] 用 `Cmd/Ctrl+Enter` 直接提交

  **预期**：跳到第一个未作答的必答题并标错，而不是提交残缺答案

## D. 界面与偏好

- [ ] 点标题栏语言按钮，界面文案整体切换。**题目正文保持原语言**（那是 Agent 写的，不翻译）
- [ ] 切换明暗：默认应与系统外观一致，按钮可覆盖
- [ ] 缩放 `A−` / `A+` / `⟲` 生效，放大后内容区可滚动
- [ ] 系统开启"减弱动态效果"后重开面板，入场动效消失

## 失败排查

| 症状 | 最可能的原因 |
| :--- | :--- |
| 点提交后 Agent 立刻报告 `cancelled: true` | 页面没走 `window.glimpse.send`，或载荷被判为取消 |
| 点提交后 Agent 一直等待 | 载荷没到达原生端（回到 `postMessage` 那类错误桥的症状） |
| 面板底部提示「无法回传结果」 | 页面拿不到 `window.glimpse`；说明 `prompt()` 未注入桥 |
| 提交后 Agent 报"答案非法" | 契约侧拒绝了自定义文本，检查 `normalizedAnswer` 的分支 |
| 面板根本没打开，直接走了 TUI | glimpseui 未安装或路径探测失败，看控制台 `[glimpse] failed to load candidate` |

## 通过标准

A–D 全部符合预期，且 A 的实际回传内容与上面的字段规则一致。任一不符：**不要合并 PR #1**，
把现象贴回变更里，先定位是面板侧还是宿主侧。
